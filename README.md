# **_ArtSpaceProject_**

**ArtSpaceProject** is an Android project that demonstrates core UI logic and navigation using **Kotlin**. *Note: Only the `MainActivity.kt` file is provided in this repository.* This decision is made to preserve academic integrity, ensuring that students develop their own complete projects without relying solely on this code.

---

## **Project Overview**

- **Core Component:**  
  - **`MainActivity.kt`** – Contains the primary UI logic and navigation flow.

- **Missing Components:**  
  The repository intentionally excludes other necessary files such as:
  - **XML Layouts:** Files under `res/layout` that define the UI.
  - **Resources & Themes:** Styles, colors, and themes that enhance the visual appearance.
  - **Supporting Classes:** Additional Kotlin classes required for a full-fledged app.

*Developers or students who wish to build a complete application will need to recreate these missing parts or integrate the provided code into a well-structured Android project.*
